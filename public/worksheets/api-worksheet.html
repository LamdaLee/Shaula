목표: 요청 주소와 응답 데이터를 연결하고, 실패를 성공과 구분할 수 있다.

나의 버튼사용자의 요청
웨이터 ↔ 주방API 요청 ↔ 서버
도착한 요리응답을 화면에 표시

비유의 경계: API는 의도를 해석하는 사람이 아니라 정해진 형식의 인터페이스입니다.

50분의 흐름

5분결과 체험5분요청 구조25분작은 구현10분성공·실패 시험5분저장·회고
수업 전 준비

시작 HTML 파일과 실행 주소를 제공합니다. 설치·계정 준비는 사전에 확인합니다. 이번 요청은 교육용 정적 JSON으로, 외부 AI나 유료 API를 호출하지 않습니다.

작동 예시: /examples/api-lab.html

작은 미션

  1. ‘자료 요청’ 버튼을 누르면 응답을 보여줍니다.
  2. 아래 주소로 요청하고 message를 꺼냅니다.
  3. 응답이 실패하면 오류 안내를 보여줍니다.

완료 기준

  • 정상 요청의 문장이 화면에 나타난다.
  • 없는 주소는 성공으로 표시하지 않는다.
  • 응답을 기다리는 중임을 알 수 있다.
AI와 구현할 요청문 초안

버튼을 누르면 아래 JSON을 fetch하고 message를 화면에 표시해 줘. response.ok가 false이면 오류를 보여줘. 기다리는 동안 버튼을 비활성화하고 성공·실패 뒤 복구해 줘. 완료를 주장하기 전에 직접 시험할 방법도 알려줘.

/examples/lesson-menu.json
{ "message": "요청한 자료가 도착했어요." }
